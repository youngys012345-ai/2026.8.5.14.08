# 资源配置清单（内网必读）

本文件随公开仓发布。内网 `git pull` 后**先读本文**，再配环境与下载数据。

机器可读副本：[`datasets.yaml`](./datasets.yaml)

---

## 1. 工作流与职责

| 侧 | 做什么 | 不做什么 |
|----|--------|----------|
| 外网 | 维护最小核心代码、本清单、脚本；`git push` | 不把内部数据/大权重推进公开仓 |
| 内网 | `git pull`、按清单下数据、训评、记结果 | 不把内部视频推回 GitHub |

实验结果：**人工**带回外网改代码，再推仓同步内网。

---

## 2. 磁盘档位（先选档再下载）

| 档位 | 内容 | 预计占用 | 建议空闲 | 适用 |
|------|------|----------|----------|------|
| **S0** | GTEA 特征 + EgoPER 特征 | 15–40 GB | ≥50 GB | 外网/盘紧时最小跑通 |
| **S1** | S0 + EgoProceL 特征/子集 | 40–80 GB | ≥120 GB | **内网主原型推荐** |
| **S2** | 再加 EgoPER/EgoProceL 原始视频 | 150–350 GB | ≥400 GB | 需自提特征时 |
| **S3** | Assembly101 全量 | ~3.89 TB | ≥4.5 TB | **禁止在小盘外网机** |
| **S4** | IndustReal（可选） | 5–77 GB | ≥100 GB | 第一轮跳过 |

另留：**特征缓存 20–80 GB**、**权重/日志 5–20 GB**（可与数据分盘）。

检查空闲：

```bash
python scripts/check_disk.py
python scripts/check_disk.py --recommend-tier
```

## 3. 数据集清单

### 3.1 主集（目标 A / B）

| ID | 数据集 | 用途 | 优先形态 | 体积量级 | 获取 |
|----|--------|------|----------|----------|------|
| `gtea_features` | GTEA | ProTAS A | I3D 特征 | 1–5 GB（Zenodo 三件套可达 ~30 GB） | [Zenodo 3625992](https://zenodo.org/records/3625992)、[ProTAS](https://github.com/Yuhan-Shen/ProTAS) |
| `egoper_features` | EgoPER | A+B | 预提取特征 | 5–20 GB | [EgoPER 官方](https://github.com/robert80203/EgoPER_official)（邮件申请） |
| `egoper_rgb` | EgoPER | 可选自提特征 | RGB 约 30–60 GB；多模态更大 | 同上；28h 720p@15fps |
| `egoprocel_features` | EgoProceL | ProTAS A | 特征/子集 | 10–40 GB 量级 | [EgoProceL](https://sid2697.github.io/egoprocel/) |
| `egoprocel_source_videos` | EgoProceL | 原始 | 全源约 100–250+ GB | 仅内网大盘 |

**EgoPER 申请**：按官方仓库说明发邮件至 `lee.shih@northeastern.edu`，说明研究用途；优先只要特征与标注，不要一上来下全模态。

| ID | 数据集 | 体积 | 建议 |
|----|--------|------|------|

## 5. 目录约定

```text
data/public/     # 公开集原始或官方打包
data/features/   # 预提取特征（训练主输入）
data/internal/   # 仅内网：内部验证标注（禁止推 GitHub）
outputs/         # 日志与权重（禁止推 GitHub）
third_party/     # ProTAS、EgoPED 上游
```

初始化：

```bash
python scripts/prepare_dirs.py
```

## 7. 推荐下载顺序（内网 S1）

1. GTEA 特征（最小、先打通 ProTAS 数据接口）  
2. EgoPER 特征 + 划分文件（同时服务 A/B）  
3. EgoProceL 特征或单子集  
4. 需要时再下 RGB / Assembly101 特征（另盘）  

**禁止**：在小容量外网机下载 Assembly101 全量或 EgoProceL 全源视频。
