# 项目流程图

```mermaid
flowchart TD
  A[修改 config.json] --> B{mode?}
  B -->|design| C[三个脚本默认只打印计划]
  B -->|run| D[可加 --run 真正执行]

  D --> E[scripts/download_data.py --run]
  E --> E1[克隆 ProTAS / EgoPER / IndustReal]
  E --> E2{download_tier}
  E2 -->|T1| E3[下 Zenodo 特征并链接到 ProTAS/data]
  E2 -->|T3| E4[HF 拉 Assembly101 特征]
  E3 --> F[scripts/train.py --run]
  E4 --> F
  F --> F1[在 third_party/ProTAS 调 main.py train]
  F1 --> G[scripts/eval.py --run]
  G --> G1[可选 ProTAS predict]
  G1 --> G2[对比 pred 与 groundTruth]
  G2 --> H[outputs/eval/exp_id/metrics.json]

  C --> Z[外网磁盘不足时停在这里]
```

## 目录角色

| 路径 | 作用 |
|------|------|
| `config.json` | 唯一常改参数 |
| `scripts/download_data.py` | 下载模块 |
| `scripts/train.py` | 训练模块 |
| `scripts/eval.py` | 评测模块 |
| `third_party/` | 上游代码（脚本自动克隆） |
| `data/` | 特征/公开数据（不入库） |
| `outputs/` | 评测结果（不入库） |
| `docs/` | 设计与说明 |
