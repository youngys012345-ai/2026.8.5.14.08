# 环境与资源指南

## 1. 硬件角色

| 环境 | 规格 | 允许的工作 |
|------|------|------------|
| 本机 | 仅 CPU | 读文档、改配置、维护划分列表、小片段 ffmpeg/抽检、汇总指标表 |
| 内网 | 多卡 GPU（单卡约 24GB 显存档） | 特征提取、训练、主评测、权重推理 |

预研默认并行占用 **2–4 卡**，不必锁满 8 卡。

## 2. 本机 CPU 边界

**可做**

- 维护 `configs/`、`docs/`、划分 txt/csv
- 小视频转码与人工看边界
- 根据评测 JSON 计算 Sequence Edit、画对照表

**不可做（放到内网 GPU）**

- 全量 I3D / 视频骨干特征提取
- ProTAS / EgoPED 训练与多数据集联合训
- 长视频端到端 VLM 推理

## 3. 存储量级（粗估）

| 项 | 量级 |
|----|------|
| 公开集原始视频 | 约 50–200+ GB（含 Assembly101 全量时偏上限） |
| 预提取特征 | 约 20–80 GB |
| 实验权重与日志 | 约 5–20 GB |
| VLM 权重（摸底阶段） | 另约 20–50 GB |

大文件放 `data/` 下对应目录，**不入库**（见根目录 `.gitignore`）。

## 4. 训练卡时量级

### 4.1 ProTAS（目标 A）

假设特征已提好；单卡 4090。

| 实验 | 卡时 |
|------|------|
| A-single × 1 数据集 | 0.5–4 GPU·小时 |
| A-single 全套（含 split/重跑） | 1–2 GPU·天 |
| A-multi（共享骨干+多头） | 1–3 GPU·天 |
| 公开集推理评测 | 数小时内 |
| 内网少量视频推理 | 分钟–数小时 |

显存：特征训练通常 8–16GB 足够。

### 4.2 EgoPED（目标 B）

| 实验 | 卡时 |
|------|------|
| 特征 + 分割骨干（首次） | 0.5–2 GPU·天 |
| CSPL 原型/对比学习 | 数小时–1 GPU·天 / 设定 |
| B-multi | 相对单任务约 +50–100% |
| EgoPER 含错评测 | 小时级 |

与 A **复用特征管线**，避免重复提取。

### 4.3 建议排期

| 周次 | 内容 | 建议占卡 |
|------|------|----------|
| W1 | 数据就绪 + 主三集特征 | 2–4 |
| W2 | ProTAS A-single + 公开评测 | 2–3 |
| W3 | ProTAS A-multi 对照 | 1–2 |
| W4 | EgoPED B-single（+可选 B-multi） | 1–2 |
| W5 | 权重迁内网 + 少量内部标评测 | 1 |

合计约 **2–3 周墙钟**；纯 GPU 约 **1–2 卡·周**。

## 5. VLM 摸底资源（第二阶段）

| 项 | 量级 |
|----|------|
| CLIP + 选帧脚本 | 0.5–1 GPU·天 |
| 7B 级 LLM/VLM 推理试点 | 1–2 GPU·天（量化可降显存） |
| 可选 LoRA 小规模 SFT | 2–5 GPU·天 |

工程约束：空镜/检测粗筛 → 切段 → **仅对段调用 VLM**，禁止全天逐帧穷尽打分。

## 6. 依赖安装

在内网 GPU 环境：

```bash
cd 长视频SOP动作提取预研
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
# 按内网 CUDA 版本安装匹配的 torch wheel
```

上游仓库克隆说明见 [third_party/README.md](../../third_party/README.md)。
