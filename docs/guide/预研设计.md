# 长视频 SOP 动作提取 · 预研设计

> 状态：已确认主线（外网公开集训练 → 内网泛化验证；单集 vs 多集对照）  
> 日期：2026-08-04  
> 关联调研：`长视频关键帧提取 ·/`

---

## 1. 背景与目标

### 1.1 业务目标

| 目标 | 定义 | 输出 |
|------|------|------|
| **A** | 识别 SOP 动作边界 | 步骤开始/结束的关键帧或时间戳 |
| **B** | 对完整 SOP 动作序列建模（包含 A） | 步骤序列；可扩展漏步/错序/偏离检出 |

### 1.2 约束（已澄清）

- 内部 SOP：长时间、**无大规模标注**；含第一人称与第三人称；可能为固定场景远景循环操作；视角/场景/实体不固定。
- 可做**少量**人工标注，仅服务验证，**不做大规模标注重训**。
- 前期以**公开数据集**训练与方法验证为主。
- 本机仅 **CPU**；训练评测在内网多卡 GPU 环境完成。
- 成功标准：双目标算法原型跑通，再迁内网用内部数据评泛化效果。

### 1.3 方法选型

| 目标 | 方法 | 角色 |
|------|------|------|
| A | **ProTAS**（因果分割 + 进度 + 任务图） | 在线/稳定步骤边界 |
| B | **EgoPED**（仅正常样本对比步骤原型） | 序列结构 + 开放集偏离 |
| 后续 | CLIP / Q-Frame·AKS / PREGO 式 LLM 等 | 语义对齐与可解释告警摸底 |

## 2. 数据与训练协议

### 2.1 总体策略

| 阶段 | 环境 | 内容 |
|------|------|------|
| P0 原型跑通 | 外网数据 + 内网 GPU | 公开集准备、特征提取、训练、公开集留出验证 |
| P1 泛化主测 | 内网 | 外网权重迁入，在**未见过的内部 SOP**上评（少量人工标作 GT） |
| P2 对照与 VLM 摸底 | 外网/内网 | 单数据集 vs 多数据集联合训；VLM 只做资源与接口摸底 |

**硬约束**：P1 主结论下，**训练不使用内部视频**，以检验泛化性。

### 2.2 公开数据集

| 角色 | 数据集 | 视角 | 用途 |
|------|--------|------|------|
| 主集 A | GTEA、EgoProceL、EgoPER（仅正确视频） | Ego | ProTAS 边界/在线分割 |
| 主集 B | EgoPER（正确训 / 含错测） | Ego | EgoPED 序列与偏离 |
| 辅集 | Assembly101（及 O 变体） | Ego+Exo | 跨视角、贴近固定机位 |
| 可选 | IndustReal | Ego | PSR/完成性对照，非第一轮必训 |

组合节奏：主三集 → 再扩 Assembly101 子集 → 内网真验。

### 2.3 联合训练架构约束

ProTAS / EgoPED 的类别空间与 Task Graph / 步骤原型均**任务相关**，不可直接混用步骤 ID。

| 形态 | 做法 | 预研采用 |
|------|------|----------|
| **M1 共享骨干 + 多任务头** | 骨干共享；每任务独立分类头与图/原型 | **第一轮推荐** |
| M2 统一文本/SOP 词表 | 步骤名映射到共享语义空间 | 留给 VLM 阶段 |
| M3 特征层联合预训练 | 多数据集预训骨干再微调 | 备选（负迁移时） |

### 2.4 实验矩阵（摘要）

**目标 A · ProTAS**

| 模型 | 训练 | 验证 |
|------|------|------|
| A-single-* | 单数据集 | 同分布留出 + 内网少量标 |
| A-multi | M1 三主集联合 | 各公开留出 + 内网少量标 |
| A-crossview | 可选含 Assembly101 | Exo 留出 + 内网第三人称 |

**目标 B · EgoPED**

| 模型 | 训练 | 验证 |
|------|------|------|
| B-single | EgoPER 正确执行 | EgoPER 含错 + 内网少量标 |
| B-multi | 多任务正确执行联合 | 跨任务含错 + 内网 |

内网：**不微调或仅冻结骨干探针**；主看零样本/冻结迁移。完整表格见 [实验矩阵](../examples/实验矩阵.md)。

### 2.5 内部标注最低规格

- 第三人称远景循环：≥ 5–10 次完整循环  
- 第一人称（若有）：≥ 3–5 条完整 SOP  
- 标注字段：步骤起止时间戳 + 步骤名  
- 覆盖 ≥2 场景更佳；有错误样本则服务目标 B，否则内网重点评 A 与序列结构

## 3. 评测指标

### 3.1 目标 A（边界）

| 指标 | 含义 |
|------|------|
| Frame Acc | 帧级步骤是否正确 |
| Edit | 切段是否干净 |
| F1@{0.1, 0.25, 0.5} | 段级重合；**主看 F1@0.5** |
| Boundary MAE / δ-Accuracy | 起止时刻误差；δ∈{0.5s, 1s, 2s} |
| Over-seg ratio | 预测段数 / GT 段数 |

报告 **online（因果）** 数字；离线仅对照。

**公开集过关**：相对「因果骨干无进度/无图」基线，F1@0.5 与 Edit 稳定提升。  
**内网过关**：能输出可读边界；分数作摸底，不设硬阈值。

### 3.2 目标 B（序列，含 A）

| 指标 | 含义 |
|------|------|
| A 全套指标 | B 必须先能切步 |
| Sequence Edit Distance（归一化） | 步骤串级主指标 |
| Step Precision / Recall | 漏步 / 多检 |
| EDA、Frame-AUC | 错误段与按帧异常（有错标时） |
| POS（可选） | 顺序合规，与 SeqEdit 互补 |

训练集**仅正确执行**；错误只出现在验证/测试。

### 3.3 单集 vs 多集对照

对每个测试域比较 multi 与 single：

- **ΔF1@0.5**、**ΔEdit**、**ΔSeqEdit**
- **Transfer Gap** = 同分布分数 − 内网分数（越小越好）
- **Win-rate**：multi 不低于 best-single 的测试域占比

读法：未见任务/视角上涨、同分布持平或略跌 → 联合有价值；全面下跌 → 负迁移，改 M3 或回调采样。

### 3.4 外网→内网泛化协议

| 项 | 规定 |
|----|------|
| 训练 | 仅公开集 |
| 验证 | 内网少量标；Ego / 远景 Exo **分报** |
| 循环作业 | 先按「第几次循环」切段，再在本圈算指标 |
| 类名不对齐 | 先报忽略类名的段级 IoU + 序列结构；有映射表再报带类名指标 |
| 主结论表 | `模型 × 测试域 × {F1@0.5, Boundary-δ, SeqEdit, (EDA)}` |

### 3.5 工程冒烟

- 固定 seed，公开集指标可复现（如 F1 波动约 ±2 可接受）
- 记录 4090 上推理延迟（特征已提前提下）
- 交付：权重 + 配置 + 评测脚本 + 内网推理命令

## 4. 训练与评测资源

详见 [环境与资源.md](./环境与资源.md)。摘要如下。

| 层级 | 环境 | 用途 |
|------|------|------|
| L0 | 本机 CPU | 配置、标注工具、报告、小片段抽检 |
| L1 | 1×4090 | 单集训练/推理/评测 |
| L2 | 2–4×4090 | 多实验并行、特征批量提取（**预研默认**） |

粗排期：**约 2–3 周墙钟**；纯 GPU 约 **1–2 卡·周**（4 卡并行可压墙钟）。内部标注约 **数小时–2 人日**。

存储粗估：公开视频 50–200+ GB；特征 20–80 GB；权重日志 5–20 GB。

## 5. VLM 语义路线后续资源

原则：少训多推理；接在切步/候选片段之后。

| 路线 | 训练 | 4090 推理 | 阶段 |
|------|------|-----------|------|
| CLIP 零样本对齐 | 免训/探针 | 轻 | 摸底优先 |
| Q-Frame / AKS | 免训 | CLIP 打分 + 下游 LLM | 摸底优先 |
| PREGO 式 LLM | 识别复用 A | 0.2–数秒/次 | 需可解释顺序时 |
| MistSense 级 | LoRA/SFT | 更重 | **暂缓**，单独立项 |

决策门：内网 A/B 已有可用边界/序列信号 → 上 CLIP/选帧；痛点在开放类名与错因解释 → 上轻量 LLM；细粒度执行质量解释 → 再立项重度 VLM。

## 6. 预研主线（收束）

```text
外网公开集（单集 + 多集联合）训练 ProTAS / EgoPED
        ↓ 权重
内网：内部少量标注评泛化（Ego / 远景 Exo 分报）
        ↓ 决策门
VLM：CLIP / 选帧 / 轻量 LLM 摸底 → 必要时再重度 VLM
```

配置入口：`configs/experiment/protocol.yaml`。

## 7. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 近景程序公开集 ↔ 远景循环内部域差大 | 分报视角；忽略类名的边界/结构指标；不设内网硬阈值 |
| 多集联合负迁移 | M1 多头；失败则退回 M3 或仅 single |
| 类名无法对齐 | 段级 IoU + SeqEdit；后续 CLIP 文本映射 |
| 本机无 GPU | 全量训练/特征提取锁定内网 |
