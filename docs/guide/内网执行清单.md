# 内网执行指令清单

> 参数文件：根目录 [`config.json`](../../config.json)。外网磁盘不足时保持 `mode=design`，**不要** `--execute` 下载。  
> 勿提交内部业务视频、权重、密钥。本文与公开方法/数据集信息无涉密内容。

---

## 1. 拉取与环境

```bash
git clone https://github.com/youngys012345-ai/2026.8.5.14.08.git
cd 2026.8.5.14.08
# 或 git pull

python scripts/prepare_dirs.py
python scripts/check_disk.py
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
# 按内网 CUDA 安装匹配 torch
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.device_count())"
```

编辑 `config.json`：

- `"mode": "run"`
- `"hardware.gpu_ids"` 按可见 GPU 修改
- 下载前：`"download_plan.allow_download": true`

---

## 2. 上游代码

```bash
python scripts/clone_third_party.py
```

- [ ] `third_party/ProTAS`
- [ ] `third_party/EgoPER`
- [ ] `third_party/IndustReal`（可选）

---

## 3. 数据集：T1 / T3

### 3.1 先看计划（不下载体）

```bash
python scripts/download_t1.py --dry-run
python scripts/download_t3.py --dry-run
python scripts/plan_datasets.py
```

### 3.2 T1（公开可获取，建议先做）

内容：Zenodo MS-TCN 特征（GTEA/50Salads/Breakfast）+ IndustReal RGB/标签（4TU 页面手工下）。

```bash
# config: mode=run, allow_download=true, datasets.*.enabled 保持 T1 为 true
python scripts/download_t1.py --execute
python scripts/link_mstcn_data.py --dataset gtea
```

IndustReal 若无直链：打开 `config.json` 里 `page`，把 zip 放到 `data/public/industreal/`。

建议空闲：**≥80–120 GB**。

### 3.3 T3（跨视角特征，禁止全量视频）

内容：Assembly101 **TSM 特征 + annotations**（Hugging Face）。

```bash
pip install huggingface_hub
# 若数据集需登录/同意条款：huggingface-cli login
# config: assembly101_features.enabled=true
python scripts/download_t3.py --execute
```

建议空闲：**≥250 GB**。不要启用 `assembly101_full`。

### 3.4 T2（可选，需申请）

EgoPER 邮件申请后再 `enabled=true`；EgoProceL 特征手工放置。

---

## 4. 训练

```bash
# 改 config.train：backend/dataset/split/epochs/...
python scripts/run_train.py --dry-run
python scripts/run_train.py
```

当前默认 `backend=ProTAS`，`dataset=gtea`。需先完成 T1 与 `link_mstcn_data.py`。

EgoPED：数据就绪后将 `train.backend` 设为 `EgoPED`，按上游 README 继续（入口会打印说明）。

---

## 5. 评测

```bash
# 可选：先让上游出预测
python scripts/run_eval.py --run-upstream-predict

# 或指定预测目录
python scripts/run_eval.py --pred-dir <预测标签目录> --gt-dir <GT目录>
```

指标写入 `outputs/eval/<exp_id>/metrics.json`（Acc / Edit / F1@k / 边界 δ）。

---

## 6. 推荐最小闭环

1. `mode=run` + clone 上游  
2. `download_t1.py --execute` + `link_mstcn_data.py`  
3. `run_train.py` → `run_eval.py`  
4. 有余力再 `download_t3.py --execute`  

设计说明见 `docs/guide/预研设计.md`。
