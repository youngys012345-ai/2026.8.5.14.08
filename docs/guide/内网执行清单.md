# 内网执行清单（精简）

## config.json（仅这些需要改）

打开根目录 `config.json`：上面的 `_help` 是字段说明（脚本忽略）；下面才是实际生效的配置。

| 字段 | 可选值 / 含义 |
|------|----------------|
| `mode` | `design` \| `run` |
| `download_tier` | `T1` \| `T3` |
| `gpu_id` | 如 `"0"` |
| `dataset` | 如 `gtea` / `50salads` / `breakfast` |
| `split` | 如 `"1"` |
| `exp_id` | 任意短名，如 `run0` |
| `epochs` | 整数备忘 |
| `pred_dir` | `""` 或预测目录路径 |

## 命令顺序

```bash
git pull
pip install -r requirements.txt
# 安装匹配 CUDA 的 torch

# 1) 改 config：mode=run, download_tier=T1
python scripts/download_data.py          # 先看计划
python scripts/download_data.py --run    # 克隆上游 + 下 T1/T3

# 2) 训练
python scripts/train.py --run

# 3) 评测
python scripts/eval.py --run
# 或已有预测：
python scripts/eval.py --run --skip-predict --pred-dir <目录>
```

IndustReal 需按日志提示从 4TU 页面手工放到 `data/public/industreal/`。  
出错时直接看终端日志；上游参数不兼容时改 `scripts/train.py` / `eval.py` 里的命令列表即可。
