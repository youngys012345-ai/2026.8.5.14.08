## 已确认决策摘要

1. **协议**：外网公开集训练 → 内网内部数据验证泛化；训练阶段不使用内部视频。  
2. **对照**：单数据集训练 vs 多数据集联合训练（优先 M1：共享骨干 + 多任务头）。  
3. **方法**：目标 A = ProTAS；目标 B = EgoPED（仅正常样本训练）。  
4. **数据**：主集 GTEA / EgoProceL / EgoPER；辅集 Assembly101；可选 IndustReal。  
5. **资源**：本机 CPU 仅轻量工作；内网多卡 GPU，预研默认少量卡并行。  
6. **VLM**：A/B 原型与内网摸底之后再做；优先 CLIP / 选帧 / 轻量 LLM，暂缓 MistSense 全量。  

## 范围边界

- **本规格覆盖**：数据协议、评测指标、资源估算、项目骨架。  
- **不覆盖**：具体训练超参调优、生产部署、大规模内部标注流水线。
