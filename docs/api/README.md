# API 文档

预研代码落地后，在此目录补充各模块接口说明。

## 规划中的模块

| 模块 | 路径 | 职责 |
|------|------|------|
| 数据 | `src/data/` | 公开集/内网划分、特征路径解析 |
| 模型 | `src/models/` | ProTAS / EgoPED 封装与多头联合接口 |
| 指标 | `src/metrics/` | Acc、Edit、F1、Boundary、SeqEdit、EDA 等 |
| 训练 | `src/train/` | 单集 / 多集训练入口 |
| 评测 | `src/eval/` | 公开集评测与内网泛化验证入口 |

当前阶段以协议与文档为主，接口随实现迭代补充。
